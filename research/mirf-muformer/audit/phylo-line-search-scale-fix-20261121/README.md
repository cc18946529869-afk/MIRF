# F81 投影步长尺度修复与独立梯度验证

**本轮结论为 NO-GO。** 新初始化让 10,000 行短初值案例越过原 Armijo 停机，接受步数从 18 增至 130。两组真实数据都耗尽原 260 次求值预算，且终点投影梯度远高于 $10^{-5}$。10,000 行的新终点也未通过 $10^{-8}$ 的独立梯度一致性门槛。

## 实现和同一点回放

从固定提交 `4fd8c7a60185539943e5125f36306bb18b6eea2f` 创建独立分支。在原可行域步长上限以内，先取投影位移 $u(\alpha)=\max(0,x+\alpha d)-x$，计算 $q=g^\top u$。当预计下降 $-10^{-4}q$ 超过当前目标 $F$ 的 1% 时，按比率缩小初始步，每次用实际浮点投影重新计算。若触边上限给出的步已经较保守，则保留该步。进入原搜索后仍使用同一个 Armijo 比较；若右侧小于 $F$ 的理论下界 0，则该试探无需调用似然。旧路径仍可用于对照。 [优化器改动](../../dcr/perf/f81_optimize.py) · [实验入口](../../dcr/perf/check_f81_line_search_scale.py)

## 高精度独立复核

沿待查枝将固定拓扑分成两个连通分量。从两端分别高精度计算子树似然，直接计算该枝的标量导数，独立于常规梯度的下行传播。对于每个位点，若两个端点的子树似然向量是 $L,R$，令 $A=\sum_a\pi_a L_aR_a$，$B=(\sum_a\pi_a L_a)(\sum_b\pi_b R_b)$，则该枝对负对数似然的导数为 $e^{-s}(A-B)/(e^{-s}A+(1-e^{-s})B)$。使用 192 bit 和 256 bit 两档 Boost 二进制浮点数，比较二者后按原口径对 263 个位点取平均。有限算术的误差拆分采用带符号恒等式 $g_{\mathrm{fl}}-g_{\mathrm{ref}}=(g_{\mathrm{fl}}-\mathrm{round}_{64}(g_{\mathrm{ref}}))+(\mathrm{round}_{64}(g_{\mathrm{ref}})-g_{\mathrm{ref}})$。

## 审查结论与复现

审计程序从日志重新计算 Armijo 左右侧的比较，核验接受步的单调性、初始投影预测上限、每次 24 个试探及总预算，并比对 MSA、行索引、权重、位点组成、拓扑和加载内核的指纹。冻结参数为 `c1=1e-4`、`maxiter=150`、`maxeval=260`、投影梯度阈值 `1e-5`、梯度绝对一致性阈值 `1e-8`。解析参考、步长初始化、原优化器回归和零边回归均通过。

运行于 `yf-Precision-7960-Tower`，4 个 CPU 线程及单线程 BLAS。归档包含构建命令、数值 JSONL、独立高精度结果、审核脚本和资源计时。真实计算限于短初值固定拓扑子集。真实观测和参数向量留在服务器。 [日志及运行脚本](raw-logs.tar.gz) · [SHA-256](SHA256SUMS)
