# L-BFGS 曲率尺度与固定方向步长扩展

**10,000 行终点的单位步上限确实限制了当前 L-BFGS 方向。** 同一方向取 $\alpha=2^{26}$ 时，两条似然路径均通过冻结的 Armijo 条件，平均负对数似然下降 0.11547，为单位步的约 31,100 倍。方向质量也有影响，两条梯度对照方向在各自的可行尺度上都找到了更大的单步下降。真实 MSA 桥接仍为 **NO-GO**。

## 曲率历史如何变化

从 `4a94e4c90271f5758808726227f8551f734a24a8` 的存档接受步重建两个检查点和曲率历史。重建逐条核对原搜索方向的范数、梯度内积、实际位移、似然和投影梯度，并核对终点向量字节与 SHA-256。重建仅评估归档中已接受的状态。扩展试探固定终点和方向，不更新优化器或检查点。 [审查入口](../../dcr/perf/check_f81_direction_scale.py)

| 轨迹指标 | 1,000 行 | 10,000 行 |
| --- | ---: | ---: |
| 归档接受步 | 118 | 130 |
| 终点投影梯度无穷范数 | $3.60\times10^5$ | $1.05\times10^{17}$ |
| 终点 L-BFGS 方向无穷范数 | 1.335 | $2.21\times10^{-11}$ |
| 终点自由坐标梯度与方向的余弦 | −0.01176 | $-2.96\times10^{-14}$ |
| 终点活跃约束 | 258 | 887 |
| 终点 $\gamma=s^\top y/(y^\top y)$ | $6.57\times10^{-9}$ | $1.83\times10^{-42}$ |
| 最后 100 步接纳的新曲率对 | 100 | 0 |
| 最后 100 步投影后与投影前位移的 $L_2$ 范数比 | 0.1243 至 1.0000 | 0.99999990 至 1.00000009 |

10,000 行最后 100 步均使用第 29 个接受步的同一个最新曲率对，$s^\top y=7.35484$，$y^\top y=4.00823\times10^{42}$。这段全部新曲率对的 $s^\top y$ 为正，却均低于既有条件 $10^{-10}\lVert s\rVert_2\lVert y\rVert_2$。因此，$\gamma$ 在进入这段前已降至极小尺度，并在这 100 步中保持固定。末段活跃集固定为 887 坐标，方向的切空间过滤与单位步投影均未把坐标再截到零。位移范数比略高于 1 的幅度与浮点舍入一致。历史停更、极小的初始逆 Hessian 尺度、以及方向与自由梯度近乎垂直同时出现。该观测不能单独确定重新缩放 $\gamma$ 后的轨迹。

## 同一终点的固定方向对照

每个方向试探从 $\alpha=1$ 至 $2^{36}$ 的二进制倍增网格，并检查原初始化给出的可行锚点附近的倍增与减半网格。第三条方向采用逐坐标归一化的投影负梯度 $d_j=-g_{\mathrm{free},j}/\max(1,|g_{\mathrm{free},j}|)$。每个试探对实际投影后的枝长检查零边可行性。可行且发生位移时，计算原路径目标，并以不同内部计算根和强制对数域复核下降。表内为采样网格中满足两条路径 Armijo 条件的最大下降，包含独立路径的平均目标变化。

| 固定终点 | 方向 | 最佳实测步长 | 平均负对数似然变化 |
| --- | --- | ---: | ---: |
| 1,000 行 | L-BFGS | $8.097\times10^{-3}$ | −0.04070 |
| 1,000 行 | 投影负梯度 | $1.362\times10^{-9}$ | −0.04278 |
| 1,000 行 | 逐坐标归一化负梯度 | $1.034\times10^{-3}$ | −0.08429 |
| 10,000 行 | L-BFGS | $2^{26}$ | −0.11547 |
| 10,000 行 | 投影负梯度 | $8.226\times10^{-32}$ | −0.21055 |
| 10,000 行 | 逐坐标归一化负梯度 | $6.949\times10^{-15}$ | −0.26193 |

10,000 行的 L-BFGS 单位步可行，下降 $3.7105\times10^{-6}$，最大位移 $2.21\times10^{-11}$。连续倍增至 $2^8$ 都通过，第一段内 $2^7$ 的下降最大，为 $2.248\times10^{-4}$。从 $2^9$ 至 $2^{20}$ 拒绝，$2^{21}$ 至 $2^{26}$ 再次通过。$2^{26}$ 的实际最大位移为 $1.485\times10^{-3}$，独立 Armijo 残差为 −0.03737。说明遇到第一次拒绝即停止扩展会保留一部分收益，同时漏掉远端的可接受区域。更远的试探中有目标继续降低但未满足充分下降的候选。1,000 行的 L-BFGS 首个零边冲突约为 $\alpha=0.54547$，三条方向都无法直接用单位步。 [完整试探账本](raw-logs.tar.gz) · [汇总 JSON](results.json)

## 工程判断与验收

固定点证据支持在小规模对照中测试受限的步长扩展，并同时比较曲率历史管理与方向归一化。两条梯度对照在单步网格上都优于扩展后的 L-BFGS，但它们的步长尺度相差多个数量级。固定点结果只给出局部下降，尚未建立哪种方案能在同一预算内收敛。后续比较应保留零枝长冲突检查和原 Armijo 条件，按实际求值预算比较。

归档终点的 $10^{-8}$ 门槛继续指两条梯度路径的绝对一致性，1,000 行通过，10,000 行最大绝对差仍为 816。与高精度参考的 binary64 表示误差是另一个量。沿用原 $10^{-5}$ 投影梯度门槛。当前分支只增加诊断工具和审查数据。两个已存档检查点共进行了 425 个固定方向探针，正式模拟、Bootstrap 和全量优化继续暂停。 [试验日志与环境](raw-logs.tar.gz) · [SHA-256](SHA256SUMS)
