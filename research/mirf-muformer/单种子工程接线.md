# 真实单种子实验的工程接线

本轮没有启动 μFormer 的 `Trainer.train`，没有调用十种子入口的训练路径，没有重算 Potts，没有重跑 Bootstrap，没有重写软权重表，没有覆盖 v0.1。下面的线性替身分数不是实验结论。

## 1. 软权重特征

`feature_align.FeatureIndex` 读取现有 `dcr/features/blat_ecolx_stiffler_2015_soft_weight_coords.tsv`，键是 `sequence`。查询按调用顺序返回 14 列 `values` 和 14 列 `mask`。缺序列直接报错。同一条序列重复查询返回同一行。标签来自训练 TSV 的 `score` 列。

归属计数写在 `dcr/reports/feature_alignment.json`：

- 表 4996 行，序列唯一。train 3497，valid 500，test 999。表内 `masked_rows` 为 0。
- n=1000 训练文件 1000/1000 在表的 train 划分。
- 全量训练文件 3497/3497 在表的 train 划分。
- 验证文件 500/500 在 valid 划分。测试文件 999/999 在 test 划分。

这是归属。逐行拼接由 `align_scored_sequences` 按调用方给出的顺序完成，测试覆盖了原始顺序、打乱、子集、重复查询和全量训练文件的 25 行子集。

`test_feature_align.py` 把真实 n=1000 前 40 行送进 `residual.fit_predictor`，并在 `_epoch` 里核对收到的 `batch["values"]` 和 `batch["mask"]` 与对齐结果相同。正式表没有 0 掩码；假掩码用临时表检查，没有改正式表。这 14 列不进入 μFormer 的 `Trainer`。

## 2. PMLM 坐标

`pmlm_coords.audit_table` 用与 `pmlm_check` 相同的词典编码检查全部 4996 行。报告是 `dcr/reports/pmlm_coordinate_audit.json`。

- 每行长度 286。长度不是 286、突变残基对不上、或位点不在成熟蛋白内，直接拒绝。
- token 0 是 `<s>`。参考位置 `r` 的 token 下标是 `r`：这是对每一行编码后，核对 `tokens[r]` 等于该位置氨基酸，而不是未检查的假设。
- 成熟位置满足 `mature_pos = ref_pos - 23`。成熟蛋白从参考位置 24 到 286，长度 263。
- 抽查位置是 24、82、182、286，以及每一行自己的突变位置。
- 两叶下标有 2 套，长度 112 和 151。一个 batch 里各行不能共用同一组 source / other 下标。
- 审计不保存隐藏状态。

`FrozenPmlm.representations` 按每一行自己的 site 下标取隐藏状态，source 和 other 也是每一行一组，长度可以不同。隐藏状态仍是时间、批次、通道。模型保持 `eval()`，参数 `requires_grad=False`，不读 `fc_reduce`。

真实权重 `pmlm_650m.pt` 的前向只在两条 source 长度不同的训练序列上做过：核对 site、source、other 与 `hidden[index, row]` 一致，通道维 1280。没有把 4996 行的隐藏状态写盘。

## 3. 单种子入口和 OOF

`single_seed.prepare_single_outer_seed` 只接受锁定的十个种子之一，以及 `n1000` 或 `full`。它读取 `dcr/precheck` 的封口折，核对每条训练行恰好被留出一次，并把该训练文件顺序上的 14 维特征放进返回的 `values` / `mask`。预检摘要是 `dcr/reports/single_seed_preflight.json`。

n=1000、种子 `1975576344` 的预检：

- `training_started`、`muformer_called`、`oof_predictions_computed`、`arms_trained` 都是假。
- 完整模型请求是 300 轮、patience 300、`restore_best=True`。
- 五折请求的轮数是 `None`：还没有该种子自己的 \(E_s\)，不填种子 42 的 229。`restore_best=False`。
- 比较配置批大小 16。残差封口批大小 64，AdamW，学习率 \(10^{-3}\)，weight decay \(10^{-4}\)，最多 300 轮，patience 30。
- 三臂名称是 `full`、`sum`、`no_potts`。这一步没有训练它们。

`run_single_outer_seed(start_training=True)` 在没有工厂时拒绝。`run_ten_outer_seeds` 和 `train_outer_models(..., mode="formal")` 仍拒绝。

`train_one_outer_seed` 在工厂给出 `predict_held_out` 时，把五折留出预测按行拼成 OOF，并拒绝重复行和缺失行。没有这个方法时，不把空预测写成已经有了 OOF。测试里的替身工厂返回的是行号，不是 μFormer 输出。

`engineering_chain.run_n1000_stand_in` 用真实 n=1000、验证和测试序列，以及真实 14 维特征。五折预测来自这些特征列上的线性最小二乘，每条训练序列恰好一条预测。残差标签是训练 TSV 的 `score` 减去这条预测。这不是 μFormer 折模型的预测，不能当作实验的 \(e_i\)。

## 4. 三条残差臂

替身链路调用 `residual.fit_predictor` 三次。三臂共用同一份初始状态，共用该外层种子的选轮随机数流。测试核对了第一轮样本顺序相同。最佳轮数可以不同。记录在 `dcr/reports/n1000_stand_in.json`：full 90、sum 90、no_potts 14。位点向量来自位置表，不是 `pmlm_650m.pt`，宽度是 8，不是 1280。封口的 \(d_s,d_l,d_r\)、批大小和优化器没有改。

## 5. 选 η 和测试集

`choose_eta_from_validation` 只接收验证标签、验证基础分和验证残差。传入测试标签会拒绝。η 的候选仍包含 0。替身这次选出的 η 是 0。测试集分数在 η 锁定之后才计算。

替身的测试集点估计也写在 `n1000_stand_in.json`。基础分是同一条线性模型，不是 μFormer。这些数不是单种子实验的结果，更不能代替十种子结论。指标定义没有改。

## 7. 启动前检查

可以做的检查已经做完：

1. n=1000 与全量的 sequence 都能在软权重表对上，14 维 `values` / `mask` 能进入 `fit_predictor`。
2. 4996 行的 token 坐标已经核对；两叶下标按行分开；冻结权重的逐行 gather 在两条真实序列上核对过。
3. 单种子入口能做启动前检查。正式训练调用仍关闭。十种子入口仍拒绝。
4. 五折索引覆盖每一条训练行一次。折模型留出预测的拼接函数已有，但真实 Trainer 还没有被要求交出留出折预测。
5. 三条臂能在真实特征上训练，目前的 OOF 标签来自线性替身。
6. η 只由验证集决定。测试集不进入选 η。

还不能当作已经启动的实验：

- 没有跑 n=1000、种子 `1975576344` 的 300 轮 μFormer。
- 没有该种子自己的 \(E_s\)。
- 没有 μFormer 五折 OOF，也就没有用它训练三条臂后的正式 η 和测试集结果。
