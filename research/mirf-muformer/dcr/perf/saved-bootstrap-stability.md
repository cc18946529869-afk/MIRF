# TEM-1 历史 Bootstrap 稳定性复算

## 输入与复算

以固定提交 ed7ef3c89acad248860d377238209ece99dc81df 的五组 Top-263 区间认证作为正式数值参考。存档参考 J 与认证文件记录的 SHA-256 一致，参考 h 与已验收点估计清单的 SHA-256 一致。复算读取历史 001–100 的 200 个参数数组，核验种子锁、重复编号、抽样索引的身份、数组维度和双三角转置关系。结果文件记录本次读取的数组哈希，供再次复算时核对。历史摘要哈希为 17f75081ac5bd4e896eedb03c428594fe0db61d328abd90103cb37de4e02dd9c。

沿用历史冻结的参数定义与双三角布局。对每个参数坐标，以独立的 Welford 中心化累积计算两半的二阶矩，再合并两半。以样本方差（分母为重复数减一）之和开平方，除以参考参数的 Frobenius 范数，得到 R。数值交叉核验采用 257 个等间距的耦合数组坐标，直接对 100 个保存值计算中心化样本方差。四个历史统计量均在绝对容差 1e-12 内复现。本次复算耗时约 52 秒。

## 参数稳定性

历史 D 的定义是全体 001–100 与前 50 次的对应 R 的绝对差，再除以全体 R。单独计算两半时，R_h 分别为 0.071010 和 0.070722，R_J 分别为 0.458147 和 0.458093。两半均值的差仅占全样本耦合中心化平方偏差的 1.02%，其余来自两半各自内部。D_J 的小值反映用前 50 次已接近全 100 次的波动量级。

## 系统发育协议复审

- **统计稳定性。** 历史程序独立按权重有放回抽取 MSA 序列行。本次复算量化的是这个重抽样律下的参数与入选集合变化。若要在系统发育相关性下估计稳定性，需明确抽样总体、依赖单元，以及希望估计的是参数归一化波动、入选重合度还是 Precision@L。谱系分组敏感性分析可用来检查结果对分组的依赖，其作为 Bootstrap 推断使用需要独立论证覆盖性。 [历史抽样源码](https://github.com/cc18946529869-afk/MIRF/blob/2f737a3dee4564c44163d7b2330997cea0dd862a/research/mirf-muformer/dcr/bootstrap_fit.py)
- **树的不确定性。** 经典按对齐列重抽样的树 Bootstrap 依赖其字符模型的假设，给出的是树的分支支持度。TEM-1 的固定坐标与固定接触标签要求另行定义评分的重抽样目标。 [Felsenstein 1985](https://academic.oup.com/evolut/article/39/4/783/6872498)
- **共享树零模型。** 该对照用于估计共享谱系背景下、无直接位点耦合时的 Precision@L 分布，作为原研究所定义的中位数位置差的基准。历史行重抽样的 R_J 和集合重合度无法确定该对照分布。树推断及枝长尺度、组成与重复序列、等权混合、评分区间及 Monte Carlo 不确定性仍是独立的协议验收项。 [Rodriguez Horta 与 Weigt 2021](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1008957)

本轮仅复算存档和审查统计解释。正式树推断和模拟维持 NO-GO。
