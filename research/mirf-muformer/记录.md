# 对齐

## 对象

预测对象是单点氨基酸替换的实验适应度。一个数据文件是一次实验，单独训练，单独和原始 μFormer 比较。不同文件的适应度标签不合并。

通过条件只使用 `BLAT_ECOLX_Stiffler_2015`。2026-11-12 用户改口：87 个文件的集合不再进入否决。该文件序列长度为 286，前 23 位是信号肽。要看的科学问题是，同一种氨基酸替换落在不同残基上，为什么实验适应度不同。

要研究的计算关系以用户 2026-11-12 修订后的 DCR 为来源：在成熟序列的一个 Potts 上，把单点突变的条件能量变化拆成规范不变的背景平均项和各集合上的上下文项；跨集合的上下文项再按固定结构的几何权重拆成界面项、非界面项和坐标缺失项。这些部分在进入预测头之前保持分开，作为残差加回原始 μFormer 的分数。同日停用的旧关系是：冻结语言模型的表征差、共进化边与动态影响边、状态传播和通信重加权。

基线评分里的序列概率项以本地代码为准。`Mu-Protein/mu-former/src/model.py` 双塔分支的 `diff_prob` 去掉首尾特殊 token，对各位点自身 token 的对数概率取平均，再两条序列相减。位点掩码后的条件对数优势比是另一个量。当前 `Mu-Protein/mu-former/src/trainer.py` 写入评估结果的是 Spearman。Pearson 出现在损失函数中。NDCG@10% 与 Top-10% Recall 在这两处没有。

## 终点与通过条件

三条否决使用同一套判定。

- 划分：只有随机划分进入否决。位置留出和替换类型留出只作补充分析。
- 样本量：只有 \(n=1000\) 和全量进入否决。\(n=300\) 和 \(n=2000\) 要做、要报告，不进入否决。验证集和测试集保持不变。产生 0.7877、0.8540、0.9055、0.9248 的四个训练文件都是全量 train 的子集，彼此不嵌套：n=300 与 n=1000 的交集是 88 行，n=1000 与 n=2000 的交集是 587 行。正式比较使用这些文件。原先写的「训练子集嵌套」与这些文件不符，该句停用。
- 种子：5 个随机种子只用于筛选。正式结果用 10 个与 baseline 配对的随机种子。报告这 10 个种子的均值、标准差、配对 Bootstrap 95% 置信区间，以及指标提升的种子数。2026-11-12 停用「只看每一个种子的点估计，不看平均，也不用置信区间」。
- 指标：Spearman \(\rho\)、Pearson \(r\)、NDCG@10%、Top-10% Recall，以及 RMSE。RMSE 于 2026-11-12 进入报告。
- 单位：只有 `BLAT_ECOLX_Stiffler_2015`。

否决 1：在 `BLAT_ECOLX_Stiffler_2015` 上，\(n=1000\) 和全量各自判定。Spearman 的正式通过要同时满足三句：10 个配对种子的平均 \(\Delta\rho>0\)；配对 Bootstrap 95% 置信区间下界大于 0；至少 8/10 个种子的 Spearman 点估计更高。\(n=300\) 和 \(n=2000\) 用同一套统计报告，不进入否决。

Pearson、NDCG@10%、Top-10% Recall 和 RMSE 随正式种子报告均值、标准差、配对置信区间和提升种子数。它们不代替 Spearman。某一辅助指标的 95% 置信区间整段落在变差的一侧时，不把结果说成各项都提高。RMSE 的差值方向是 baseline 减 DCR，正值表示误差下降。NDCG 与 Top-10% Recall 的正值表示 DCR 更高。

\(K=\lceil 0.1 N_{\mathrm{test}}\rceil\)。这份测试集 \(N_{\mathrm{test}}=999\)，所以 \(K=100\)。Top-10% Recall 是预测前 \(K\) 与真实标签前 \(K\) 的交集大小除以 \(K\)。NDCG@10% 先用完整测试集的固定最小值和最大值把标签线性映射到 \([0,1]\)，gain 为 \(2^{\mathrm{rel}}-1\)，折损为 \(\log_2(\mathrm{rank}+1)\)，再除以同一 gain、折损和 \(K\) 下的理想 DCG。排名并列时用该行序列作为固定的变体标识。2026-11-12 确认：Bootstrap 不在每个重抽样里重算 min/max；每次抽取 \(N_{\mathrm{test}}\) 个测试样本，\(K\) 仍由完整测试集的行数决定。

配对 Bootstrap 固定 10000 次：有放回抽取种子，再有放回抽取测试变体；baseline 与 DCR 使用同一批测试索引；先算每个被抽中种子的指标差，再对种子取平均；区间取 2.5% 与 97.5% 分位数。

否决 2 的参数量匹配 MLP 仍无输入定义。否决 2 的静态图和否决 3 的 DCI 图没有对应计算，这两句不执行。

实验前不把未跑出的提升幅度写成结果。TEM-1 上的机制分组不进入否决。按动态影响强弱分组随旧假设停用。

## 已确认的边界

原始 μFormer 的训练条件不变。不改比较用的数据划分口径，不用测试集调参，不用会泄漏标签的数据增强，不把其他实验的适应度混进该文件的标签。

残差分支使用冻结的预训练 PMLM，不使用微调后的 μFormer 隐状态，也不使用 `fc_reduce`。表征在最后一个 Transformer block 的输出、LM head 之前提取，`eval()` 且不求梯度。2026-11-12 用户确定不采用 v1.0 的联合训练和 \(s_{\mathrm{DCR}}\) 惩罚。

五折只划在外层训练集内部。每一折用其余四折从头训练一个原始 μFormer，初始化用同一个预训练 checkpoint，超参数与该种子的 baseline 相同。折模型的训练轮数取该种子完整 μFormer 在外层验证集上选出的最佳 epoch。每条训练样本只有一条 OOF 预测。残差标签是 \(e_i=y_i-\hat y_i^{\mathrm{OOF}}\)。

残差预测器只在 OOF 残差上训练，损失是 MAE。输出层零初始化。它的优化器、学习率、批大小和早停轮数仍是建议，没有钉死。早停用外层训练集内部另划的 10% 子集；选定轮数后，用全部 OOF 样本按该轮数重训。外层测试集不参与训练、选轮数或选 \(\eta\)。

最终预测是完整外层训练集上的 μFormer 分数加 \(\eta r_\theta\)。\(\eta\) 在 \(\{0,0.05,\ldots,1\}\) 中选择，外层验证集上 Spearman 最高；Spearman 相同则 RMSE 更低；仍相同则取更小的 \(\eta\)。\(\eta=0\) 时预测等于该 μFormer 分数。

DCR 的科学特征是 14 个数：\(R_i^{\mathrm{mean}}\)、\(\Delta E_i\)、二者的 Bootstrap 标准差；来源叶瓣的 \(R\) 及其标准差；另一叶瓣的 \(R\)、界面项、非界面项、坐标缺失项及这四项的标准差。来源叶瓣不做几何分解，对应位置用掩码，不用 0 充当观测。这 14 个数不是 14 个相互独立的信息源：Bootstrap 均值满足 \(\Delta E_i=R_i^{\mathrm{mean}}+\sum_k R_{i\rightarrow k}\)，跨叶瓣项再满足 \(R_{i\rightarrow k}=R_{\mathrm{contact}}+R_{\mathrm{remote}}+R_{\mathrm{unknown}}\)。实验报告给出这些特征的相关，以及下面两条对照。不使用 \(\log(1+N_{\mathrm{eff}})\)。

几何权重是 \(g_{ij}=\sigma((8-d_{ij})/1.5)\)，距离取 1BTL Chain A 的 Cβ，甘氨酸用 Cα，单位是 Å。坐标缺失的残基进入 unknown 项。结构不随突变重算。1BTL 不是 ProteinGym 野生型序列：REMARK 450 写明 V84I 与 A184V，对应参考位置 82 和 182。这两处侧链是否仍用这份坐标，尚未决定。

两个叶瓣按 1BTL Chain A 与 286 位参考序列的一一对应划分，结果在 `research/mirf-muformer/prep/domain_map.tsv`。螺旋叶瓣是 author 62–212，即 ProteinGym 60–210，151 个位点，`lobe_id=1`，`lobe_name=H`。其余已有坐标的成熟位点是 author 26–61，以及 213–238、240–252、254–290，即 ProteinGym 24–59 与 211–286，共 112 个位点，`lobe_id=0`，`lobe_name=AB`。author 编号在 239 和 253 空缺，链的末端是 290，不是 288。263 个成熟位点互斥且并集完整，全部有 CA。信号肽 1–23 行的 `mapped=0`，不进入 Potts。论文中的名称是结构叶瓣。Maveyraud 等，JBC 1996，正文写 helical domain 为残基 62–212，二级结构归到 Jelsch 等 1993。26–61 与 213–288 不是该文的第二个引用范围；213–288 也不能当作这条链的末端。

位点表征 \(h_i^{\mathrm{mut}}\) 和两个叶瓣平均 \(z_{\mathrm{AB}}^{\mathrm{mut}}\)、\(z_{\mathrm{H}}^{\mathrm{mut}}\) 都取同一条变体序列的最后一层输出，各自属于 \(\mathbb{R}^{d}\)。不与野生型表征拼接，不恢复消息差分。位点投影的输入宽度是 \(d\)，共享叶瓣投影的输入宽度是 \(d\)，同一组权重用两次。14 是科学特征的个数。掩码 \(m\in\{0,1\}^{14}\) 与数值拼成 \(x_{\mathrm{DCR}}^{\mathrm{input}}=[x_{\mathrm{DCR}}\odot m;\, m]\)，这一张量的宽度是 28，DCR 投影读的是这 28 维。拼接满足 \(d_s+2d_l+d_r=160\)：\(d_s\) 是位点投影的输出宽度，\(d_l\) 是叶瓣投影的输出宽度，\(d_r\) 是 DCR 投影的输出宽度。\(d_s,d_l,d_r\) 尚未取值。\(64+32+32+32=160\) 只是这个等式的一个例子，不是已经选定的宽度。拼成 160 维之后，再经 64 维 GELU、dropout 0.1 和零初始化的一维输出。这里的 64 是拼接之后的那一层，不是 \(d_s\)。这里不使用注意力。

\(\log n_{\mathrm{train}}\) 在一次训练中对所有突变是常数，不作为按突变变化的特征。\(\log(1+N_{\mathrm{eff}})\) 同样不进入特征。

# 假设

草稿正文保留。2026-11-12 用户停用消息差分假设，并把 DCR 的分解改成下面的规范不变形式。审查结论写在「论证」。用户还没有对这一节说可以，落实方案不因此通过。

成熟序列长度 \(L=263\)，对应参考序列的位置 \(24,\ldots,286\)。Potts 只建在这 263 个位点上。\(\{D_k\}\) 是这 263 个位点的一个划分。TEM-1 上这两个集合是结构叶瓣。按 `research/mirf-muformer/prep/domain_map.tsv`，ProteinGym 1-based 的 60–210 是螺旋叶瓣，24–59 与 211–286 是另一叶瓣。

能量是

\[
E(S)=-\sum_i h_i(s_i)-\sum_{i<j}J_{ij}(s_i,s_j).
\]

单点替换 \(m=(i,w\rightarrow a)\) 的条件能量变化是

\[
\Delta E_i=E(S^{\mathrm{Mut}})-E(S^{\mathrm{WT}})=-\Delta h_i-\sum_{j\neq i}\Delta J_{ij}(w_j),
\]

其中 \(\Delta h_i=h_i(a)-h_i(w)\)，\(\Delta J_{ij}(b)=J_{ij}(a,b)-J_{ij}(w,b)\)，\(w_j\) 是野生型在 \(j\) 的氨基酸。\(i>j\) 时按 \(J_{ij}(x,y)=J_{ji}(y,x)\) 延拓，使 \(j\neq i\) 的和与能量式里的 \(i<j\) 指同一组耦合。

设 \(q_j(b)\) 是位点 \(j\) 的加权频率，加伪计数后对 \(b\) 求和为 1。令

\[
\mu_{ij}=\sum_b q_j(b)\,\Delta J_{ij}(b),\qquad u_{ij}=\Delta J_{ij}(w_j)-\mu_{ij}.
\]

\[
R_i^{\mathrm{mean}}=-\Bigl(\Delta h_i+\sum_{j\neq i}\mu_{ij}\Bigr),\qquad
R_{i\rightarrow k}=-\sum_{j\in D_k,\,j\neq i}u_{ij}.
\]

于是

\[
\Delta E_i=R_i^{\mathrm{mean}}+\sum_k R_{i\rightarrow k}.
\]

在不改变序列概率的规范变换下，\(\Delta J_{ij}(b)\) 增加一个与 \(b\) 无关的常数 \(c_{ij}\)。这个常数同时进入 \(\mu_{ij}\)，所以 \(u_{ij}\) 不变。字段的补偿与 \(\sum_j c_{ij}\) 抵消，所以 \(R_i^{\mathrm{mean}}\) 不变。各 \(R_{i\rightarrow k}\) 也不变。

对 \(k\neq d(i)\)，几何权重沿用对齐里已经写明的 \(g_{ij}=\sigma((8-d_{ij})/1.5)\)。\(d_{ij}\) 是突变前取定的 1BTL Chain A Cβ 距离，甘氨酸用 Cα，单位是 Å。有坐标的位点同时进入界面项和非界面项，不是三个互斥子集：

\[
R_{i\rightarrow k}^{\mathrm{contact}}=-\sum_{\substack{j\in D_k\\ j\neq i\\ j\in\mathrm{coord}}} g_{ij}u_{ij},\qquad
R_{i\rightarrow k}^{\mathrm{remote}}=-\sum_{\substack{j\in D_k\\ j\neq i\\ j\in\mathrm{coord}}}(1-g_{ij})u_{ij},
\]

\[
R_{i\rightarrow k}^{\mathrm{unknown}}=-\sum_{\substack{j\in D_k\\ j\neq i\\ j\notin\mathrm{coord}}} u_{ij}.
\]

三项之和等于 \(R_{i\rightarrow k}\)。参考位置 82 和 182 的 PDB 氨基酸不是野生型，这两处算不算有坐标，对齐尚未决定，几何三项随这个取舍有条件。突变位点自己所在集合不使用这三项。

送入残差的是这些分量，以及它们在 Bootstrap 样本上的标准差。标准差是另一组特征，不把分量替换成收缩值，所以上面的加和仍对 Bootstrap 均值成立。\(\log(1+N_{\mathrm{eff}})\) 对一次拟合的全部突变是常数，不作为按突变变化的特征。

预测是 \(s_{\mu\mathrm{F}}+\eta r\)。\(r\) 在把各分量相加之前分别接收它们。\(\eta\) 只在验证集上选择，可以为 0。训练方式若改成共享微调编码器，或改成对 \(s_{\mathrm{DCR}}\) 加惩罚而不再使用 \(\eta\)，要先改对齐里已经写明的残差协议。

贡献是这一段计算：把单点 \(\Delta E\) 拆成规范不变的背景平均项和各集合的上下文项，跨集合的上下文项再拆成界面、非界面和坐标缺失三项，并且在进入 \(r\) 之前保持分开。理由是总和固定时，上下文在集合之间的分配仍可以不同；按距离丢掉其余耦合的做法不再保留非界面项。别人可以继续把突变位点所在集合的 \(u_{ij}\) 再按几何权重拆开。共享的域编码器、零初始化输出层和 TEM-1 上只有一个其他集合时的注意力，是读出。那个注意力权重是 1。

计算上成立的是加和恒等式，以及上述规范变换下 \(u_{ij}\)、\(R_i^{\mathrm{mean}}\) 和 \(R_{i\rightarrow k}\) 不变。超出证据的是：上下文项等于结构叶瓣内的物理相互作用能，非界面项等于别构通信。

## 可区分性

与单一 \(\Delta E\) 重叠的是它们的和。新信息是相加之前的各部分。两条替换可以有相同的 \(\Delta E\) 和不同的 \(\{R_{i\rightarrow k}\}\)，也可以有相同的跨集合 \(R_{i\rightarrow k}\) 和不同的界面项、非界面项。

与 ECNet 重叠的是 Potts 耦合和语言模型可以同时进入预测。新信息不是位点耦合向量。与 Thakur 等重叠的是结构距离可以给耦合响应加权。新信息是非界面项仍然保留。

若读出只接收 \(R_i^{\mathrm{mean}}+\sum_k R_{i\rightarrow k}\)，新信息退回 \(\Delta E\)。若残差同时接收语言模型表征，而没有一条去掉这些 \(R\) 的对照，分数变化不能归因于 \(R\)。

## 对预测的影响

当前 `Muformer.forward` 读不到这些 \(R\)。两条单点替换的 \(s_{\mu\mathrm{F}}\) 和 \(\Delta E\) 可以相同，而 \(\{R_{i\rightarrow k}\}\) 不同。\(r\) 在相加前接收这些分量，\(\eta\neq 0\)，且 \(r\) 不是 \(s_{\mu\mathrm{F}}\) 与 \(\Delta E\) 的函数时，预测可以不同。\(\eta=0\) 时退回原始 μFormer。

`BLAT_ECOLX_Stiffler_2015` 上的 Spearman 通过条件是平均提升、置信区间下界和至少 8/10 个种子。它不辨认增益来自哪一个分量。v1.1 的读出不用注意力。指标会不会提高，超出证据。
