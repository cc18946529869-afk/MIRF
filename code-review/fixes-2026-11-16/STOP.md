# STOP 的数学设计

这里没有训练代码。当前策略仍是固定 H 次编辑，没有 STOP 动作。

一条轨迹在时刻 t 的序列状态记为 s_t。t 或剩余编辑次数必须是策略和价值网络的输入。现在的观测是 [WT, x_t]，同一个序列在不同剩余次数下会得到同一个输入。

## 1. 联合动作概率

每个时刻先决定 z_t ∈ {STOP, CONTINUE}。CONTINUE 之后再选位点 ℓ_t 和氨基酸 c_t。STOP 不再选这两项。

\[
\log \pi(a_t\mid s_t,t)
=
\log \pi_{\mathrm{gate}}(z_t\mid s_t,t)
+
\mathbb{I}(z_t=\mathrm{CONTINUE})
\left[
\log \pi_{\mathrm{site}}(\ell_t\mid s_t,t)
+
\log \pi_{\mathrm{aa}}(c_t\mid s_t,\ell_t,t)
\right]
\]

现有的边际探索混合只放在位点和氨基酸上：每个因子是 0.75 乘策略概率，加 0.25 乘该因子的均匀分布。STOP 不进入位点 softmax，也不改变位点个数 K。门控本身不乘这组 0.75/0.25。

## 2. 联合 PPO ratio

旧策略记为 π_old。一个时间步只有一个联合 ratio：

\[
\rho_t
=
\frac{\pi(a_t\mid s_t,t)}{\pi_{\mathrm{old}}(a_t\mid s_t,t)}
\]

CONTINUE 时它是门控 ratio、位点 ratio、氨基酸 ratio 的乘积。STOP 时它只剩门控 ratio。clip 作用在这一个 ρ_t 上。分别 clip 三项再相乘，不等于 clip 联合 ratio。

## 3. STOP 时的价值

使用一个共享状态价值 V(s_t, t)。它不接收位点。

现在的第二个价值头吃的是拼上位点之后的观测。STOP 没有位点，这个头没有合法输入。因此 STOP 设计不沿用第二个价值头，也不在 STOP 步更新它。

## 4. GAE

CONTINUE 的即时奖励是 0。只有 STOP，或编辑次数达到 H_max，才调用 MuFormer，并把该分数作为这一步的奖励，然后轨迹结束。终止后不再 bootstrap，最后一步的下一状态价值是 0。

GAE(λ) 沿这条变长轨迹计算。λ 仍沿用当前的 0.95，作为初始值；这一项不是本设计要调的量。

## 5. 时间特征

门控、位点策略、氨基酸策略和 V 的输入都包含同一个时间特征。可以用已经用掉的编辑次数，或剩余可编辑次数。二者差一个已知的 H_max，选哪一个都要在实现前固定，并且训练和采样使用同一个。

没有这个特征时，固定 H 的前馈网络也无法区分“同一序列、不同剩余次数”。这对以后的 STOP 是必须补上的输入，本阶段不改网络。

## 6. 变长轨迹的终点预算

预算是 4998 条已经完成并评分的终点序列。不能再用固定的 total_timesteps。变长之后，每条轨迹的环境步数是随机的，现有 learn 循环按步数截断，不能保证终点条数。

以后的循环应按完成的终点计数。到达 4998 时可以做完当前这条轨迹，但不能再开始新的轨迹。这个循环现在不写。

## 7. γ = 1

中间奖励为 0 时，长度为 H 的轨迹回报是 γ^{H-1} 乘终点分数。γ = 0.99 时，第一步的折扣是：

| H | γ^{H-1} |
| --- | ---: |
| 5 | 0.9606 |
| 7 | 0.9415 |
| 10 | 0.9135 |

同样的终点分数，轨迹越长，回报越小。γ = 1 时回报等于终点分数，长度本身不加分也不减分。这是初始方案。它不表示更长的序列应该更好。

## 8. 怎样发现过早停止

不设手工长度惩罚，也不另加熵奖励。

深度 0 不允许 STOP。否则直接给 WT 打分并停止就是合法最优。H_max 取有限值；与后续深度实验对齐时用 10，但那不是现在就训练。

要记录停止步的分布、终点汉明距离和终点分数。若策略在第一个允许停止的时刻停止，平均终点汉明距离停在 1，或终点分数没有超过固定 H=5 的已有筛选，就认为出现了过早停止。那时自适应深度没有得到支持。

动作轨迹日志只记录位点、替换前后的氨基酸、空编辑、重复位点和最终汉明距离。它不禁止重复位点，也不把 H 解释成不同位点的个数。
