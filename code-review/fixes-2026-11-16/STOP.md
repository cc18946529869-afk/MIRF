# STOP 的数学设计

这里没有训练代码。当前策略仍是固定 H 次编辑，没有 STOP 动作。

动作之前，已经执行的编辑次数是 \(t\)，剩余可编辑次数是 \(H-t\)。当前观测是 \([WT,x_t]\)，没有这一项。时间特征选定为剩余次数 \(H-t\)，不选已经执行的次数。固定 Horizon 和 STOP 使用同一个定义。

## 1. 联合动作概率

每个时刻先决定 \(z_t\in\{\mathrm{STOP},\mathrm{CONTINUE}\}\)。CONTINUE 之后再选位点 \(\ell_t\) 和氨基酸 \(c_t\)。STOP 不再选这两项。

\[
\log \pi(a_t\mid s_t,H-t)
=
\log \pi_{\mathrm{gate}}(z_t\mid s_t,H-t)
+
\mathbb{I}(z_t=\mathrm{CONTINUE})
\left[
\log \pi_{\mathrm{site}}(\ell_t\mid s_t,H-t)
+
\log \pi_{\mathrm{aa}}(c_t\mid s_t,\ell_t,H-t)
\right]
\]

现有的边际探索混合只放在位点和氨基酸上：每个因子是 0.75 乘策略概率，加 0.25 乘该因子的均匀分布。STOP 不进入位点 softmax，也不改变位点个数 \(K\)。门控本身不乘这组 0.75/0.25。

氨基酸动作仍然可以选择当前氨基酸。空编辑不禁止，重复位点也不禁止。

## 2. 什么时候允许 STOP

STOP 只在当前序列与 WT 的汉明距离大于 0 时合法。汉明距离为 0 时，门控里的 STOP 被掩掉，这一步只能 CONTINUE。

因此下面这条轨迹不成立：第一步把某位点写成它已经具有的氨基酸，序列仍是 WT，第二步 STOP。第二步的汉明距离仍是 0，STOP 非法。

深度 0 只是这条规则的一个特例，不是单独的补丁。以后发生的空编辑只要没有把汉明距离留在 0 以上，也不能 STOP。已经离开 WT 之后，后续的空编辑不再取消 STOP。

到达 \(H_{\max}\) 时轨迹必须结束，不论当前是不是自愿 STOP。若此时序列仍是 WT，不再调用 MuFormer，分数复用已知的 WT 分数。这条轨迹仍占用 4998 个终点名额中的一个，避免用连续空编辑把搜索延长。它不是一次成功的自适应停止。

## 3. 联合 PPO ratio

旧策略记为 \(\pi_{\mathrm{old}}\)。一个时间步只有一个联合 ratio：

\[
\rho_t
=
\frac{\pi(a_t\mid s_t,H-t)}{\pi_{\mathrm{old}}(a_t\mid s_t,H-t)}
\]

CONTINUE 时它是门控 ratio、位点 ratio、氨基酸 ratio 的乘积。STOP 时它只剩门控 ratio，并且这一步的汉明距离必须大于 0。clip 作用在这一个 \(\rho_t\) 上。

## 4. 价值

使用一个共享状态价值 \(V(s_t,H-t)\)。它不接收位点。

现在的第二个价值头吃的是拼上位点之后的观测。STOP 没有位点，这个头没有合法输入。STOP 设计不沿用第二个价值头，也不在 STOP 步更新它。

固定 Horizon 若先只加入剩余次数，两个现有价值头都要读到这个数：位点价值读 \([WT,x_t,H-t]\)，氨基酸价值读 \([WT,x_t,H-t,\ell_t]\)。那是固定 Horizon 的输入修正，不代替这里的共享价值。

## 5. GAE

CONTINUE 的即时奖励是 0。合法 STOP，或到达 \(H_{\max}\) 且序列不是 WT 时，才调用 MuFormer，并把该分数作为这一步的奖励，然后轨迹结束。终止后不再 bootstrap。

这一设计使用 \(\gamma=1\)、\(\lambda=1\)。中间奖励为 0 时，任意长度上每一步的优势都是 \(S-V_t\)。终点分数的系数是 1，不随停止时刻变化。

\(\lambda\) 若留在现在的 0.95，即使 \(\gamma=1\)，第 \(t\) 步对 \(S\) 的系数仍是 \(0.95^{L-1-t}\)，\(L\) 是该轨迹的实际长度。长轨迹仍被压低。所以这里不把 \(\lambda=0.95\) 留作 STOP 的初始值。

## 6. 时间特征

门控、位点策略、氨基酸策略和 \(V\) 的输入都包含动作之前的剩余次数 \(H-t\)。第一步看到的是 \(H\)，最后一次仍可编辑时看到的是 1。

固定 Horizon 的观测现在是长度 \(2L\) 的 \([WT,x_t]\)。位点网络和它的价值读这份观测；氨基酸网络和它的价值在后面再拼上位点。剩余次数加在序列观测的末尾、位点下标之前，四个读数才都带有同一个剩余次数。取值范围包含 \(0,\ldots,H\)，决策时实际用到的是 \(1,\ldots,H\)。

这项改动还没有写进 `LandscapeEnv`。写进去之后，已经完成的 H=5 不再是对照。

## 7. 变长轨迹的终点预算

预算是 4998 条已经结束的轨迹，不是 4998 次新的 MuFormer 调用，也不是固定的 `total_timesteps`。自愿 STOP 且汉明距离大于 0 的轨迹调用一次 MuFormer。被迫停在 WT 的轨迹复用已知分数，不增加 oracle，但仍计入这 4998 条。

现有 learn 循环按环境步数截断，表达不了这个计数。以后的循环按结束的轨迹计数。到达 4998 时可以做完当前轨迹，但不能再开始新的轨迹。这个循环现在不写。

## 8. 怎样判断过早停止

不设手工长度惩罚，也不另加熵奖励。平均终点汉明距离等于 1 只作为描述，不作为判定。

按停止时的剩余次数，以及停止时的汉明距离，分别报告：

- 轨迹数和比例。
- 终点适应度的分布。
- 该深度上的最佳适应度。
- 终点汉明距离的分布。
- 在汉明距离第一次变成正数的那个状态就 STOP 的比例。
- 与同一观测、同一 \(\gamma=1\)、同一 \(\lambda=1\)、同样 4998 条终点的固定 H=5 相比，最佳适应度和平均适应度差多少。

若停止集中在汉明距离刚变成正数的第一个状态，并且最佳适应度没有超过上面那个固定 H=5，就认为出现了过早停止。自适应深度这时没有得到支持。

动作轨迹继续记录位点、替换前后的氨基酸、空编辑、重复位点和最终汉明距离。记录不改变动作是否合法。
