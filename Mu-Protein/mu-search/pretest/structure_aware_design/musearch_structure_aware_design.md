# 结构感知的突变搜索：技术设计与审查

结论是否决。2026-11-17 的结构条件化决策假设不成立。本文件登记用户提出的六类结构信息、现有 1XPB 能提供的数、现有 PPO 接口，以及对照 StructEvo 和 Frisby 与 Langmead 之后的贡献边界。它不是通过的落实方案，不授权改搜索代码。

假设作者是 [写结构条件化决策假设](20e0413c-7b5e-474a-a898-b59b43d170f1)。审查是 [审查结构条件化假设](c34f1a27-b2a6-4f54-a70d-96426ecd09eb)。审查第一句是「假设不成立」。操作定义、可区分性、对预测的影响都不成立。论文贡献没有达到，记 P1。

## 1. 审查判定

要引入的量是候选替换 \(a=(i\rightarrow b)\) 的局部结构描述 \(\Phi_{\mathrm{str}}(X_t,i,b)\)。两个已有策略头每一步读当前序列、突变状态和这个描述；所选替换执行后更新局部结构状态；完整序列的分数只在轨迹终点由冻结的 MuFormer 给出。

\(X_t\) 是当前序列。\(M_t\) 是每个位点是否与起始序列不同。这两条序列已经是 `env.py` 第 107–109 行的观察，所以 \(M_t\) 不是新信息。\(\Phi_{\mathrm{str}}\) 的自变量写了当前序列、位点和候选字母。相对溶剂可及面积、二级结构、埋藏深度、氢键、盐桥、芳香堆积、侧链完整性、逆折叠概率和局部能量，假设都写明不构成它的值。记录里没有从 \((X_t,i,b)\) 算出一个数或向量的式子。

位点头在 `on_policy_algorithm.py` 第 214–222 行先选位点，再把位点拼进观察，由氨基酸头选字母。位点头当时没有字母 \(b\)。只凭这一层读不到带 \(b\) 的描述，不使假设不成立。氨基酸头可以在位点确定后面对 20 个字母，但 \(\Phi_{\mathrm{str}}\) 不是数，没有进入氨基酸分布。`env.py` 第 58 行已经会改写字母。坐标不随这次改写改变。下一步没有新的几何状态，四项指标也没有一条只差这一描述的对照。

论文贡献的三件事没有达到。写出来的模型改动是两个已有 MLP 再读一个未定义描述。把几何图网络的输出、逆折叠概率或 Rosetta 能量送进这两个 MLP，仍是接入。

有一句超出证据，但不挽救假设。假设写「没有氢，依赖氢坐标的氢键和盐桥没有可核对的定义」。DSSP 用主链重原子放置氢再计算氢键。盐桥可以用带电侧链重原子的距离定义。没有实验氢坐标，推不出这两类相互作用没有定义。本轮没有采用具体截断，也没有计算它们。\(\Phi_{\mathrm{str}}\) 因此仍然没有数值。

## 2. 1XPB 已经核对过的内容

TEM-1 的实验结构用已经验证过的 1XPB 链 A，不另换 PDB。链 A 与搜索位点 24–286 逐残基对应，263/263。蛋白原子只有 C、N、O、S，没有氢。没有替代构象，占有率都是 1。Cα 的 B-factor 从 7.01 到 27.21。HETATM 是 135 个水分子和 5 个硫酸根原子。没有金属，没有底物。硫酸根不是底物。位点 1–23 没有坐标，仍是 286 个合法动作中的一部分。

对齐里已经有的接触计数是：263 个 Cα 中，距离小于 8 Å 且搜索编号差不是 1 的边有 1,093 条。这是空间邻接的计数，不是 \(\Phi_{\mathrm{str}}\)。侧链是否完整，这一轮没有数成。主链 N、CA、C、O 是否每个残基都在，这一轮也没有逐残基重数，所以二面角没有算出来。

没有底物结合构象。功能环境里不能写入底物、抑制剂或辅因子接触。催化位点是否沿用先前记录，不在本轮重数，也不放进策略输入。

## 4. 候选替换描述

\(\Phi_{\mathrm{str}}(X_t,i,b)\) 要回答的是：在当前结构背景下，把第 \(i\) 位换成字母 \(b\)，局部结构可能怎样变。假设没有给出这个函数。

第一层是 ProteinMPNN 或 ESM-IF1 的 \(q_i(b\mid S_0,X_t)\)。本轮没有调用这两个模型，也没有打开这两篇原文，所以不引用恢复率或似然比的具体数字。可以核对的限制是：逆折叠概率描述的是序列与给定主链的相容程度。它不是实验适应度，不是突变后的坐标。用户要求它只做策略输入、不做奖励、不做硬过滤。这三条限制成立，但没有概率表，它仍然填不上 \(\Phi_{\mathrm{str}}\)。位点 1–23 没有主链坐标，在这些合法动作上这个条件概率没有定义。

第二层是所选突变或少量候选的侧链重排，以及

\[
\Delta E_{\mathrm{local}}=[\Delta E_{\mathrm{rep}},\Delta E_{\mathrm{sol}},\Delta E_{\mathrm{HB}},\Delta E_{\mathrm{elec}},\Delta E_{\mathrm{packing}}].
\]

本轮没有调用 Rosetta。五个分量没有对应的能量项、截断半径和单位。即使用户规定它们是结构变化描述而不是适应度，它们现在也不是数。FastRelax 会移动侧链和主链，成本高于读坐标。没有协议，就不能规定它只对选中的动作运行。

只把节点上的氨基酸身份改成当前字母或候选字母、坐标仍用 1XPB，不是突变体构象。图网络可以把身份变化传到空间邻居，传出去的仍是野生型几何上的身份变化。

## 5. 现有 PPO 接口

这些是当前代码的接口，不是已经批准的改造。

观察是 `MultiDiscrete`。长度是 \(2\times 286=572\)，每个分量是字母表下标，字母表长度 20。位点策略读这 572 维。氨基酸策略读这 572 维再拼上刚选的位点，共 573 维。`MultiDiscrete` 的每个分量是整数类别，放不进溶剂可及面积、距离或能量这样的浮点数。要把浮点结构量送进策略，必须改观察空间。这一改动没有批准。

采样时，`on_policy_algorithm.py` 第 280 行把当时的观察写入 rollout buffer。以后若有结构量，也必须在这一刻复制进 buffer。在 `train()` 里按后来的分数或后来的坐标重算，会把未来信息写进过去的对数概率。

奖励在未到 Horizon 时为 0。Horizon 固定为 5。到第 5 步才调用 `get_fitness`。一次搜索的候选评分预算是 4,998。结构计算的时间单独记录，不计入这 4,998 次。MuFormer 保持冻结。

位点 1–23 没有坐标，仍是合法动作。任何以后写出来的结构量，都要给这 23 个位点一个确定的缺失值。不能靠删掉它们来使公式成立。

## 7. 与 StructEvo、Frisby 与 Langmead 的边界

用户图片链接没有对应到可核对的论文段落，不作为文献。

StructEvo（arXiv:2609.39048）已经把参照主链的结构编码放进分层策略。第 4.1 节把序列表示的差投影后加到 ESM-IF 的参照主链编码上，相加之后还有交叉注意力。第 4.2 节先选位点，再选字母。字母是氨基酸网络的输出，不是结构特征的自变量。奖励在序列完成时给出。第 5.3 节写去掉结构信息后平均适应度下降 9.6%（AAV-hard）和 17.0%（GFP-hard）。表 3 设置 (2) 与这两个百分比一致：AAV-hard 从 0.83 到 0.75，GFP-hard 从 1.00 到 0.83。这些是该文自己的基准，不转到 TEM-1。

因此，「结构编码器加序列编码器加先选位点再选氨基酸的 PPO」不能作为这里的贡献。StructEvo 的结构编码随序列差在特征空间里变化，坐标仍是参照主链。用户希望多出来的部分，是候选字母 \(b\) 所对应的局部化学变化进入下一步决策。这个部分正是 \(\Phi_{\mathrm{str}}\) 没有写出来的部分。它还没有成为与 StructEvo 不同的计算关系。

Frisby 与 Langmead（10.1186/s13015-021-00195-4）式 (9) 是 \(\mu(s_i)+\beta\sigma(s_i)\)，\(\beta=0.05\)。式 (10)–(12) 把同一个因子乘到整条序列的获取函数上。结构情形下这个因子是 FoldX 的 \(\Delta\Delta G\)，步骤是 RepairPDB 再 BuildModel。它作用在整条序列的分数上，不是某一个候选字母的局部描述，也不是接触边上的成对系数。若把 Rosetta 的局部能量直接当成获取函数或奖励，就靠近这一先例，而且违反用户自己写下的「能量不是适应度、不做硬过滤」。若只把它当作策略网络的又一个输入，则回到接入，贡献仍然没有达到。

ProteinMPNN、ESM-IF1 和 GVP-GNN 的方法句，本轮没有打开原文。不把恢复率或网络宽度写成已经核对的事实。假设作者的阅读是：这三篇的概率或网络读的是给定主链，不把「只改字母、坐标仍是野生型」定义成突变体构象。这一限制与本轮的否决一致，但具体数字未核对。

## 8. 停在这里

没有新的计算关系，就不进入实现。以后若要重写假设，最小的缺口是一条可以核对的式子：从 \((X_t,i,b)\) 和 1XPB 的哪些原子，算出哪一个数；哪些量固定在野生型坐标上，哪些量随候选字母变化；位点 1–23 上这个数是什么。然后写明这个数进入哪一个策略头的分布，以及一条只差这个数的对照如何改变四项指标。位点头在选出位点之前没有 \(b\)，要单独写明，不能靠对 20 个字母做汇总来补顺序。

下面三条出现任意一条，就再次否决，不实现：

- 计算最后是把距离、B-factor、逆折叠概率或 Rosetta 能量拼进现有两个 MLP。
- 计算与 StructEvo 的序列差融合加交叉注意力是同一关系。
- 局部能量被乘上或替代 MuFormer 的终点奖励。

本轮没有改 `env.py`、`dirichlet_ppo.py`、`on_policy_algorithm.py` 或 MuFormer。没有训练，没有搜索，没有使用 A6000。
