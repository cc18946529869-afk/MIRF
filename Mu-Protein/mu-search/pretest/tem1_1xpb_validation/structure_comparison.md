# 1XPB、1ZG4 和 1BTL

三份结构都按各自的 Cα 残基序列与 286 位搜索序列做全局比对。共同有坐标的搜索位置是 263 个，也就是第 24 至 286 位。

| 结构 | 与搜索序列一致的位点数 | 不一致 |
| --- | --- | --- |
| 1XPB | 263 / 263 | 无 |
| 1ZG4 | 261 / 263 | 第 82 位 I 对 V，第 182 位 V 对 A |
| 1BTL | 261 / 263 | 同样两处 |

在这 263 个位置上，Cα 叠合后的均方根偏差是：1XPB 对 1ZG4 为 0.1758 Å，1XPB 对 1BTL 为 0.4782 Å，1ZG4 对 1BTL 为 0.4178 Å。

截断距离 13 Å、使用全部 783 个非刚体模态时，`dci_functional_to_i` 的 Spearman 是：1XPB 对 1ZG4 为 0.9966，1XPB 对 1BTL 为 0.9911。DFI 的对应值是 0.9994 和 0.9980。两处残基差异和坐标差异没有把 ANM 的位点排序改成另一套。后续若使用一份晶体，序列匹配的是 1XPB。1ZG4 和 1BTL 保留为背景对照。

本机没有 DSSP 或 FreeSASA。相对溶剂可及表面积和二级结构没有计算。静态对照只使用 8 Å 内的 Cα 接触数。
