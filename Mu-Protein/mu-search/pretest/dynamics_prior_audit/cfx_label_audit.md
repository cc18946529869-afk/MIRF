# 头孢噻肟单突变标签是否在本地

这次要回答的是：高动态耦合、适中柔性的位点，是否在 TEM-1 的头孢噻肟有益单突变里稳定富集。

## 本地表实际标的是什么

ProteinGym 替换实验元数据里，`BLAT_ECOLX_Stiffler_2015` 的 `selection_assay` 是：

`Growth (10-2500 ug/mL ampicillin)`

同一张表里，Firnberg 2014 是氨苄青霉素生长，Deng 2012 的选择类型是氨苄青霉素抗性，Jacquier 2013 是阿莫西林抗性。Chen 2020 是 VIM-2，不是 TEM-1，而且氨苄青霉素、头孢噻肟和美罗培南写在同一条描述里。这些行都不是一份 TEM-1 头孢噻肟单突变表。

本地 Stiffler 划分共 4996 条，相对搜索用的 286 位序列全部是单点。它的规模和 μProtein 论文所说的“大约 5,000 个单点”相同，但元数据写的选择条件是氨苄青霉素，不是头孢噻肟。论文说 CFX 微调使用 Stiffler 的头孢噻肟数据。那份头孢噻肟单突变表不在当前文件里。`mmc4-cfx.aligned.tsv` 仍然没有找到。

因此这两句话同时成立：论文描述过一份头孢噻肟单点训练集；现在能打开的 Stiffler 表被 ProteinGym 标成氨苄青霉素。不能把后者当成前者。

## 为什么 16 条 MIC 也不够

`CFX_test_from_pan.tsv` 是头孢噻肟 MIC，但只有 A40、E102、M180、G236 四个位点的全部组合。位点级富集需要许多不同位点的单突变。四个位点不能估计“高耦合位点的有益比例是否更高”，也不能做按残基分组的交叉验证。

## 退出

关联分析没有读取氨苄青霉素分数。程序里的检验会拒绝含有 ampicillin、且没有写明 cefotaxime 的实验描述。高动态耦合加中等柔性是否在头孢噻肟有益突变中富集，这次没有可计算的标签，所以没有得出富集，也没有得出不富集。按这一阶段的退出条件，不进入位点策略的修改。
