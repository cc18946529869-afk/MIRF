# 头孢噻肟数据的来源

上一阶段排除的是 ProteinGym 文件 `BLAT_ECOLX_Stiffler_2015`。它的元数据选择实验是 `Growth (10-2500 ug/mL ampicillin)`，共 4996 条。那一条排除没有检查 Stiffler、Hekstra 与 Ranganathan 2015 年 Cell 论文是否另外做过头孢噻肟实验。

## 原文表格

Cell 论文 DOI 是 10.1016/j.cell.2015.01.035。Europe PMC 记录它不在 PMC，补充材料标记为没有。Unpaywall 给出的 PDF 地址是 `http://www.cell.com/article/S0092867415000781/pdf`，这次下载返回 403。Table S4 没有拿到。因此没有 4,997 条连续适应度，也不能核对原文里的筛选浓度、野生型基准和缺失值。没有从热图读数，也没有用氨苄青霉素分数代替。

Modi 与 Ozkan 2018 的图注把这组实验写成氨苄青霉素 625 mg/mL、头孢噻肟 0.15 mg/mL。这两个单位没有在 Table S4 里复核。eLife 2021 源数据的列名是 AMP39、AMP156、AMP625、AMP2500，数字 625 与图注相同，但列名本身没有写明单位。

## 实际使用的文件

Ardell 与 Kryazhimskiy，eLife 2021，10:e73250，PMC8765753。Figure 1—source data 2 的标题是头孢噻肟有益突变在氨苄青霉素中的附带效应分类。文件 `data/elife73250_fig1_data2.csv` 的 MD5 是 `43d2fab740bec7b3f9c14c64db7083ae`，与 Europe PMC 记录一致，共 2790 行。

正文写明 Stiffler 数据有 4,997 个点突变，头孢噻肟每个突变一次测量，氨苄青霉素每个浓度两次重复。他们把头孢噻肟中测到的适应度为正的突变称为耐药。适应度是突变体与野生型频率比的对数变化，实验约两小时；他们把 log10 换成自然对数后除以 6。这个文件没有适应度列，只有突变名和四档氨苄青霉素附带效应。19 行突变名是 `NA`，已排除。其余 2,771 个突变名唯一。

编号按成熟 TEM-1 的 Ambler 编号解释，跳过 239 和 253。这样每个野生型字母都与 286 位搜索序列一致。1XPB 作者编号另有 51A 和缺号 57，那一套编号没有用于这些突变名。2,771 个突变分布在 252 个位点。另外 11 个成熟位点在这份阳性名单里没有任何替换：Ambler 32、180、192、224、230、231、233、244、261、270、283。

这不是完整的连续标签。位点分析把名单中的替换计为阳性，把没有出现的 19 种替换中的其余替换计为不在这份阳性名单里。分母 4,997 等于 263 乘 19。平均每个位点约有 55% 的替换进入这份“一次测量为正”的名单，所以它不是严格的显著有益突变集合。
