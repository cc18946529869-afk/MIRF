# 已有工作和还没有做的事

这次没有提出新的位点公式，也没有改搜索。

Modi 与 Ozkan，Int. J. Mol. Sci. 2018，19:3808，已经在 TEM-1 上用 DFI 和 DCI 分析 Stiffler 的 4,997 个单突变，并同时讨论氨苄青霉素和头孢噻肟。他们的动力学来自全原子分子动力学，不是这次的 ANM。把 DCI 或 DFI 用来筛选 TEM-1 头孢噻肟位点，本身不是新的生物学主张。

Kazan 等人，eLife 2022，11:e67474，发布日期 2022-12-06。ICDC 把 DFI、DCI 和家族共进化放进同一套位点分类。文中对 TEM-1 的实验对照写的是 Stiffler 数据里的氨苄青霉素降解或 MIC，不是这次的头孢噻肟阳性名单。结构动力学和共进化的简单合并已经发表。

Ardell 与 Kryazhimskiy，eLife 2021，10:e73250，使用了 Stiffler 的头孢噻肟和氨苄青霉素测量，但公开的源数据是附带效应分类，不是可供重新拟合的连续适应度表。

StructEvo 已经把结构表示放进分层动作的 PPO。给 μSearch 的位点 logits 加一个固定 DCI 权重，既不是那篇工作，也没有在相同 MuFormer 预算下证明搜索更好。

因此，固定的 DCI 表不能写成这项搜索的创新。用适应度反馈在搜索过程中更新结构决策，只是一个尚未检验的候选方向。当前这份阳性名单没有给出 DCI 或 DFI 的独立位点关联，所以这一步不进入 PPO。
