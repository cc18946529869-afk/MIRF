# 与公开 DFI-DCI 实现的对照

对照仓库是 `SBOZKAN/DFI-DCI`，提交 `c89c0b3d401d5640b94395a754fe087d9aaf1eef`。计算用 1XPB 的 263 个 Cα，顺序与 `tem1_1xpb_validation/residue_mapping_1xpb.csv` 相同。上一阶段的均匀弹簧、13 Å 截断、三个笛卡尔方向的结果没有被覆盖。

## 公式差别

`dfi_dci.py` 的七个扰动方向是三个坐标轴，加上三个面内对角线和 `(1,1,1)`。每个方向先归一化成长度 1，七次响应幅度再平均。负方向没有出现。上一阶段只平均了三个坐标轴。

`dfi_calc.calchessian` 把距离的平方记成 `r`，弹簧常数写成 `100**3 / r**3`，也就是 `1,000,000 / 距离的六次方`。`calc_covariance` 不传入截断距离，所以默认没有截断。伪逆把小于 `1e-6` 的奇异值设为 0。1XPB 上这样的奇异值正好是 6 个。上一阶段使用均匀弹簧、13 Å 截断，并丢掉最低的六个模态。

`get_dci` 只定义功能位点被扰动后、位点 i 的响应与该位点平均响应之比。矩阵先除以总和，这个公因子在比值里消去。反方向仍按每个功能位点自己的平均响应归一化，不和正向平均。参考实现下两个方向的 Spearman 是 0.7776。

仓库脚本的命令行本身不能直接运行：`dfi_dci.py` 调用了尚未赋值的 `files`，并且把 `len(sys.argv == 4)` 写成条件。本次对照的是其中的函数公式。

## 排序差别

参考计算与上一阶段 1XPB 特征的 Spearman：正向 DCI 0.9450，反向 DCI 0.9492，DFI 0.9761。七方向和距离加权弹簧改变了排序，但没有换成另一套名次。两个方向不能互换，这个结论在参考公式下仍然成立。

溶剂可及表面积和二级结构没有计算，本机没有 DSSP 或 FreeSASA。
